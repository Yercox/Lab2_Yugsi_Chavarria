Bienvenidos

Este sitio fue creado como parte de la Práctica 2 de Fundamentos de Sistemas Web. Su objetivo es practicar el trabajo colaborativo con Git y GitHub usando únicamente HTML.

¿Qué encontrarás aquí?

  1. Sobre nosotros: quiénes somos y qué tecnologías usamos.
  2. Pasatiempos: lo que nos gusta hacer y un formulario de contacto.

Flujo de trabajo del proyecto

  • main: versión de producción.
  • pruebas: validación de funcionalidades.
  • desarrollo: integración de las ramas de cada integrante.
  • feature-*: trabajo individual de cada estudiante.
